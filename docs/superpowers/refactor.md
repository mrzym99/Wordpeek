你是资深桌面端架构师。请为一款基于 Tauri + Rust + React 的跨平台划词软件设计技术方案，不要输出代码，只要工程方案与风险边界。

目标：
1. Windows 和 macOS 都支持监听用户划词。
2. 快捷键监听，读取不到内容时，可访问剪切板，默认不访问，也能尽量获取用户选中文本，并判断用户是否真的发生了划词。
3. 划词图标在划词时自动出现，点击图标或双击选词时自动出现卡片，此行为禁止访问剪切板。
4. 弹出的小卡片在点击外部时自动消失，如果鼠标在卡片内部就不要消失，可以在卡片右上角添加 pin 的图标，支持 pin 住不消失。

约束：
- 前端 React 只做 UI，不直接访问系统能力。
- Tauri 负责窗口、托盘、权限引导、IPC；原生能力在 Rust 层实现。
- Windows 优先考虑 UI Automation，不用剪贴板 hack。
- macOS 优先考虑 Accessibility API，并处理辅助功能权限、Secure Input。
- 全局鼠标/键盘输入只用于判断手势，不用于猜文本。
- 需要说明：目标应用管理员权限、安全桌面、锁屏、全屏游戏/DirectX、终端、自绘应用、密码框等场景的限制。
- 需要说明卡片点击外部消失的两种模式：可聚焦窗口用 blur 失焦；无焦点/穿透窗口用全局鼠标命中测试。
- 需要给出去抖、误触过滤、同文本去重、对于格式不对的内容进行格式化(比如空格、换行异常)、划词中不关闭卡片、显示后不抢焦等交互细节。

输出格式：
- 总体架构
- 平台分层设计
- 状态机
- 权限与失败降级
- 卡片显隐策略
- 推荐库/技术方向，不贴代码
- 风险清单与测试矩阵
